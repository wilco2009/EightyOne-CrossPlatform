# EightyOne-CrossPlatform — release mirror

This repository only mirrors the **releases** of EightyOne Cross Platform, so the
emulator's *Help > Check For Updates* can query them (Codeberg blocks automated
access to its API).

- Source code, issues and development: https://codeberg.org/wilco2009/EightyOne-CrossPlatform
- Releases here carry the same zip as the Codeberg ones.
